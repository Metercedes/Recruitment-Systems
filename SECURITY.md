# Security policy

This is a portfolio project. It is not deployed and holds no real data.

The vulnerabilities documented in `docs/security-review.md` are present in the repository history
on purpose, so the review can be checked against the code it describes. They are fixed on `main`.

If you find an issue in the current code, please open an issue describing the affected file and the
conditions needed to trigger it. Since there is nothing running to exploit, public disclosure is
more useful than a private report.
